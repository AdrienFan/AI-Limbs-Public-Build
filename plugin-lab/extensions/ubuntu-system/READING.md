# Ubuntu 输出事件 v0.1.19

OutputProcessor 的 isCompleted=false 事件为逐行增量；isCompleted=true 的 outputChunk 为此前输出的完整快照。进程和普通命令消费者在发送命令前安装收集器，只追加增量，完成事件提供非空快照时替换最终缓存并关闭状态，不再次追加全量快照；这样也保留进度行覆盖和取消消息。完成事件只有状态、无输出时保留已收到的增量。

进程读取增加 has_more、next_offset 和 retained_start_line。缓冲仍保留最多 4000 行或 2 MiB，单行上限 64 KiB，每次最多读取 1000 行；超过保留窗口的输出不属于完整历史。调用方应按绝对行偏移续读。

本地未编译或运行测试。安装后用 300 行输出核对 total_lines=300，并检查最后一行和顺序，同时检查普通命令的换行与终止状态。
