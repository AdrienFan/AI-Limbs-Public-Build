# 隐私安全审计 0.1.0

安装云端产出的 `.ailp`，在 Plugin Center 批准插件身份和声明的宿主 scopes，再从工具箱进入“隐私安全审计”。payload APK 是插件内部文件，不应作为独立 Android 应用安装。

当前版本复用 AI Limbs 已授权的 ADB/Shizuku Shell，推荐 build121。无需 Root，不创建 VPN。先“立即扫描”，查看覆盖与盲区；连续监测默认关闭。每个应用的详情和风险都有独立采样时间，UNKNOWN 不代表安全。

“权限与后台限制”进入系统设置。插件内临时停用必须先暂停监测，再对具体普通应用确认；系统组件、关键组件与共享 UID 不允许停用。恢复只使用本插件记录的原启用状态。

导出主动写入手机下载目录，完成路径显示在首页；不会上传审计数据。历史页可分页查看并检查本地链一致性。

完整设计和验证范围见仓库 `docs/TODO/privacy-audit/`。云编译成功、实际安装、Host/Resident 展示和多小时运行仍需要设备验收。
