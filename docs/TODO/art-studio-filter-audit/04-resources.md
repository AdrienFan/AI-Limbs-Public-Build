# 第四阶段：最后五项具体滤镜与资源机制

本阶段补齐半色调、索引颜色、扩散颜色、颜色迁移、调色板量化的声明范围内源码实现。仍未构建、部署或实机验收，整轮收尾前不推送云端。既有 48 项滤镜参数合同保持。

## 五项实现

半色调接画室自己的参数化图案生成器，支持 dots、lines、diamonds，图案尺寸、角度、偏移、硬度、超采样、反转及各通道附加角度。处理强度、独立 RGB 和 alpha 三种模式。强度模式按前背景预乘颜色混合，再乘源 alpha；独立通道保留源 alpha，alpha 模式保留源直通 RGB 并筛网化透明度。完全透明的原像素及发光 RGB 保持。它不等同于 Krita 的整个生成器注册表、ICC 转换和硬度／噪声 LUT。

索引颜色支持 1–4 条四级色坡，以 D65 Lab 插值生成坡内、坡间和可选对角色；null 可关闭基色。可按最接近颜色对合并到指定上限，再以加权 Lab 距离映射，并独立量化透明度。最大 512 种生成色，整数插色数量有限制。D65 工作模型、颜色合并和舍入与 Krita 的 ICC Lab16／冗余合并不同。

调色板量化复用共享颜色工作区的实际颜色值，支持 D65 Lab、扩展 sRGB 或线性 RGB 距离、4×4 Bayer 有序偏移和最近两色阈值抖动。透明度可保留、裁切、指定透明色索引、Bayer 抖动或乘调色板颜色 alpha。保留原数组次序及重复颜色的索引，完全相同距离按先出现的颜色选择，不做零距离除法。颜色被量化成透明时，将其直通颜色写入独立隐藏面。

颜色迁移使用 alpha 加权非透明像素的 D65 Lab 均值与标准差，逐轴做分布迁移，保留源 alpha。统计采用 Welford 更新，原 alpha 为 0 的发光像素不参与统计。源轴零方差时，该轴的定义结果为参考均值，不假造源方差。参考值和来源标识成为参数快照，历史重放不再访问参考层；默认统计是明确标注的中性预设，可在参数窗替换。它不是 Krita 的 ICC Lab16 模型。

扩散颜色支持有界／无界、欧氏／城市街区／棋盘距离，以及扩展 alpha／保留 alpha。欧氏使用精确平方距离变换，后两者使用 4／8 邻接多源 BFS；不是 Krita 的 256／362 近似路径距离，因此欧氏边界和同距取色可能不同。源为 alpha>0 的像素，可显式加入已有隐藏色。expand 将影响区 alpha 设为 1，包含原半透明源；原 alpha=0 且 RGB 非零的发光数据保持。preserve 仅填独立隐藏色，完全不把隐藏 RGB 写作可见预乘 RGB。

新五项按整体 RGB 处理，透明度由各自模式定义；没有另加会造成透明颜色歧义的通道开关。现有选区混合仍控制最终输出，不限制源采样或统计范围。

## 隐藏颜色的独立表示与生命周期

图层新增可选 hiddenColors 对象，包含 format=1、标准嵌套 asset、width、height。资源为 F16 颜色面，RGB 是带独立有效覆盖率预乘的隐藏直通颜色，alpha 表示该面有效覆盖率；它不进入 ArtRenderer 的可见合成。隐藏直通 RGB 限于 ±65504，源 alpha=0 的发光 RGB 继续留在原可见缓冲，二者不混用。

滤镜确认在一个 MENU_LAYER_CHANGE 中同时写入可见层及隐藏面；预览只在内存中计算，不编码资产或写历史。软选区在最终输出处混合隐藏面的覆盖率及颜色，原选区外隐藏数据保留，最终非透明位置清除隐藏面像素。计算、编码或历史提交失败时清理本次新建资源。

采用已有嵌套 asset 引用，因此工程保存、活动／非活动历史、资源租约、归档导入重映射及图层复制都能保留隐藏面。已有签名规则将 asset 引用归一化，导入后的 MENU_LAYER_CHANGE 来源签名不依赖旧资源 ID。历史事件类型、工程主格式和插件身份未变。

隐藏面属于动画 cel，复制 cel 保留，blank cel 清除。普通像素／几何编辑改变其基准，或画布尺寸改变时，清除此层当前隐藏面；撤销可恢复，其他 cel 独立。其他菜单滤镜替换栅格时也不继承未处理的旧隐藏面。这一清除规则已写进入口说明，当前不承诺在任意后续画笔、变形操作中局部更新隐藏颜色。

普通合成预览和图像导出不包含隐藏面；.ailart 工程归档保留。可通过 filter.hidden 读取隐藏值，或以 alphaMode=expand、useHiddenSeeds=true 显现。这不是透明 PNG 隐藏 RGB 导出支持，不应据此承诺 PNG 纹理工作流已经接通。

## 手机与兰儿的资源入口

新增 3 项只读能力，均已同步声明、注册、参数与帮助：

- plugin.art.studio.filter.resources 返回共享调色板颜色快照、修订及图案种类。palette 直接传颜色数组；ramps 每四个颜色一坡，最多 16 个基色。
- plugin.art.studio.filter.reference 要求 documentId、expectedRevision、layerId，读取 paint／image／vector／group 根图层自身合成，不含画布背景。返回 referenceStats，可原样传颜色迁移参数。空透明参考拒绝；范围和数值不符也明确拒绝。
- plugin.art.studio.filter.hidden 要求工程修订、图层、x／y，读取 stored-canvas 坐标的独立隐藏颜色及有效状态，不读取可见或发光 RGB。

五项仍使用 filter.catalog 查询、menu.preview 预览和 menu.execute 应用，没有单独的算法副本。catalog 给出辅助能力名称及每项参数、限制、调用模板。

手机参数窗可选共享调色板并固定颜色值；索引色按原顺序每四色成为一坡，可继续编辑 JSON。参考图层读取放在可中断后台任务，关闭参数窗会取消，手动编辑了统计值时不让稍后返回的参考覆盖新输入。菜单使用现有颜色工作区刷新状态，不另做高频资源读取。

例如从参考层取得统计后，预览／应用请求为：

```json
{
  "action": "filter.color_transfer",
  "parameters": {
    "referenceStats": {
      "model": "lab-d65",
      "mean": [50, 0, 0],
      "std": [15, 10, 10]
    },
    "amount": 1
  },
  "documentId": "DOCUMENT_ID",
  "expectedRevision": 0
}
```

示例数值表示中性预设；实际参考图层使用 filter.reference 返回的整份 referenceStats。共享调色板在采用后编辑／删除，不改变此前已经确认或再次应用的参数值。

资源滤镜预估 128 字节／画布像素，另有最近色查找、生成色数量、超采样等预算。没有分块大图处理，超限拒绝，不自动缩图。Filter 元数据改为每个叶合同一行，分组保留结构，并沿用 modified-UTF8 常量上限检查。
