# 第一阶段：公共处理与首批邻域滤镜

用户已要求逐步完成整轮滤镜功能，全部完成后才统一推送云端编译。当前阶段不推送、不构建，保留 0.2.99 已发布操作语义和历史格式。

范围：不可变线性浮点输入、预乘 alpha 的模糊、带边界的卷积、通道选择、预算和取消；高斯／普通／运动／镜头模糊、基础锐化／浮雕、反锐化及高通。参数和菜单、AI 入口、只读预览共用处理代码。预览按原尺寸计算后缩小，取消不产生历史，确认仍使用 captured documentId/revision。

待后续阶段：组内／变换写回、专用曲线和资源编辑器、其他颜色／艺术／映射算法、非破坏滤镜层及滤镜蒙版、G’MIC 单独方案。不能把首阶段交付表述为整轮完成。

验证计划：浮点常量、透明边缘、邻域选区混合、非有限参数、预算、取消、卷积与通道开关；Android 上核对预览前后修订不变、一次确认一条历史及撤销／归档。测试源码随实现准备，云端执行保留到整轮收尾。

## 源码进度

2026-10-31：本阶段源码已接线，待统一构建和运行验收。

- 新增 ArtNeighborhoodFilters：独立输入／输出、边缘重复取样、预乘 alpha 的可分离高斯／光圈／普通核／运动采样；负系数卷积在线性直通 RGB 上计算，保留源 alpha；输出只在最后套用选区。
- 15 项新算法：4 种模糊、锐化、去除均值、反锐化、高通、6 种浮雕及上边缘检测。固定卷积核参考用户提供的 Krita 源码；反锐化可选择线性亮度模式或逐通道，线性亮度模式不是 Krita 的 Lab 模式。高斯参数为标准差 sigma，不冒用 Krita 的半径参数定义。
- 每个新算法有菜单参数和共享执行分支。新增菜单默认为 RGB 通道，模糊另可处理 alpha。新增算法总处理估算为 80 字节／像素，邻域取样预算为 2.5 亿 pixel-taps，超限明确拒绝；这是全图计算阶段，尚未实现分块处理，不承诺任意大图和大半径都可执行。
- 新增只读 menu.preview 能力及参数窗后台预览。原尺寸计算后缩小，白底显示当前层自身像素，不是整幅多图层画面的预览；不写资源、历史或 lastFilter。200ms 防抖、单工作线程、任务中断和代次检查阻止旧结果覆盖新参数。关闭／确认释放预览位图；确认复用菜单的版本校验和历史逻辑。
- 已发布 7 项算法计算语义保留。菜单预览和首批新算法仍要求可编辑的根像素图层；组内／仿射处理安排在后续步骤。

本阶段后，开发源码的具体滤镜清单为 22 项有实现、31 项仍缺漏。设备仍运行原安装版本，本数字不是已部署／实测通过数；核对报告的 7／46 是开始时的快照。
