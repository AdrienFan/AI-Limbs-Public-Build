# 页面与文件菜单

进入页面先checkingCanvas=true，restoring=false；核对revision标记为空则直接接受空状态。只有存在工程且缓存修订不同才恢复像素。恢复期间新建、打开、打开最近和导入打开不读取旧画布，可使用；真正写入及导出仍互斥，其余画布命令继续等待已核对帧。

快照和资产句柄在页面互斥锁内捕获，像素合成在锁外完成。文件切换沿用StudioRenderRequests票据作废旧恢复，接受帧前再次核对实际修订，旧画不能覆盖新工程。页面释放借用、关闭清空帧、异常显式重试与原保存确认保持。尚需部署验证空画室重进、新建/打开抢先执行、有工程返回和恢复失败重试。[DONE]
