# 无线调试配对浮窗

原状：开发者选项会覆盖权限插件页面，端口和配对码只能通过分屏录入。现有 build122 已提供 `host.window.overlay@1` 和 Host-local overlay page 协议。

目标：点击“打开开发者选项”时创建可拖动、可收起、可关闭的配对浮窗；配对后在同一窗口填写连接端口启动服务。页面和浮窗共享当前展示实例中的临时输入，复用原有业务 controller。

范围：权限插件页面、展示入口、临时表单状态、Provider 声明及 scope、文档和版本。仅同步编译 SDK 中基座已经存在的通用 overlay page 接口；不修改基座行为和独立权限服务端。

- [x] 共用临时表单及明确的操作反馈，提交和关闭时清除配对码
- [x] 注册 Host / Resident 同语义的浮窗 Provider 和卸载清理
- [x] 通过通用浮窗原语创建窗口，确认创建成功后跳转开发者选项
- [x] 无浮窗权限时停留在系统授权页，明确说明返回重试
- [x] 版本、说明、源码差异检查及状态流程用例编写
- [ ] 编译后真机验证系统配对窗口、输入法、拖动、收起/关闭和后台配对

编译和测试按仓库执行规则，需要明确的构建请求后执行。实际系统可能控制应用浮窗的显示；不得将应用窗口宣称为能覆盖任意系统安全窗口。

源码实现已完成；未运行构建或测试。build122 基座与 v0.2.2 服务端继续使用，新增包为 v0.2.3。
