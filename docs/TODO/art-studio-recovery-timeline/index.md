# 画布恢复与动画时间轴响应

阿伟报告部署版0.2.76持续显示正在恢复画布，以及时间轴操作延迟高。设备日志未保存这次画室卡住的异常，不能声称已经在设备上复现或验收。

## 1. 恢复流程 [DONE]

源码确认恢复状态只在初始refresh成功路径结束。若操作替换该请求，perform接收了有效画布却保留restoring=true，busy也无法释放。统一在acceptFrame结束恢复；失败显示明确错误并释放忙碌状态；被替换且没有有效画布的初始读取只再请求一次。退出页面不再发起请求。

另一个复杂历史开销是content先复制整层所有关键帧再删除轨道字段，edit又复制每条轨道。现在只深拷贝当前帧内容字段，保留轨道本身；capture仍深拷贝编辑后的内容，防止帧间共享可变对象。历史事件、选择性撤销与原生工具均保留。

## 2. 时间轴响应 [DONE]

定位帧追加历史后多次完整回放、复制完整operations，并为每个轨道组合全部600列。新增单文档派生状态缓存，SHA-256绑定工程、base和每条事件。完全一致读取返回独立可变副本；严格一致前缀的普通新增事件只回放增量。撤销、重做、同长度替换、导入和工程切换执行完整回放。完整验证仍在每次新状态末尾执行，异常不更新缓存。

缓存只保留一个JSON状态和事件散列，不保存View/Bitmap或跨进程指针。文件锁、版本校验、历史事件与原有能力响应契约保留。forEditor只让页面读取省略operations载荷；历史时间轴标签、分支和状态仍在。工具调用默认完整快照不变。

时间轴水平滚动保留完整长度与所有帧号，但只组合可见列及邻列。动画预览保持同一来源关键帧时复用已绘制像素，播放帧号与时钟继续更新。导出不使用预览图片。
