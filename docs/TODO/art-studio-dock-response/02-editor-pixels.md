# 状态与像素分离

旧编辑事务无条件重新合成画布，播放配置和保持帧也要等整图。新增ArtEditorPixels投影合成器输入：工程ID、尺寸、背景、当前已解析图层、着色层选中状态、参考图资源、洋葱皮状态；启用洋葱皮且存在轨道时纳入帧号及完整关键帧。

播放范围、帧率、循环、普通图层名称/锁定、原生选区叠加不属于合成像素。摘要相同时，新StudioRenderFrame保留新工程快照与revisionMarker，使用独立引用计数共享不可变像素，不共享旧版本状态。编辑结果直接捕获，避免再次读取工程构造快照。

播放开始时，在版本一致且没有洋葱皮/着色编辑叠加的情况下借用已完成画布，静态/保持cel立即显示；切换不同cel按原路径绘制。借用通过帧Lease释放，不回收编辑画布。

页面mutex仅覆盖编辑与资源捕获，像素计算移至锁外。停靠布局只使用Store自身事务锁，不等待页面渲染mutex。原serial/marker验收保留，旧渲染不能覆盖新工程。

新增回归测试源码覆盖播放设置/静态seek/元数据复用、内容/透明度/尺寸变化、洋葱皮、着色选中与参考资产、图层预览隔离，以及共享资源的过期任务释放。未在本地运行测试或编译。

部署验收：静态画定位不同帧及同一cel保持帧不出现reused=false整图渲染；不同关键帧/内容修改仍正确更新；帧率与循环更新及时，撤销/足迹版本正确；洋葱皮正确；退出/重入不回收仍在显示的图片。日志新增reused状态、operation名称与layerPreview阶段，便于区分后续瓶颈。实际画面改变仍需合成，本轮不承诺复杂作品首次重绘达到实时。
