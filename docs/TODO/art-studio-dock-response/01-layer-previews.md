# 后台图层预览

旧View.onDraw绘制笔画、解码资源，缩略图虽小仍占用主线程。新View只绘棋盘格与完成位图。异步预览隔离所选图层及其子树，使用普通合成器，在锁内捕获稳定资源句柄，锁外绘制128像素预览。

每页至多一个预览渲染任务，已完成图按真实内容摘要复用，最多保留16项。颜色、纹理、软选区、图层组变换、像素操作都使用同一合成器。图层改名、锁定、帧率变化不重新绘制预览；图层内容、尺寸、透明度或当前cel变化会更新。

每个显示View持有位图借用。替换/离开先解除View借用再释放，过期任务取消后丢弃结果，退出清空缓存。失败明确记录，不回退到主线程绘制。

部署验收：反复展开/折叠图层、拖动透明度、切换到颜色/足迹/动画；对比主线程Skipped frames、layerPreview及editorOperation耗时。检查多层/组/纹理/动画预览正确，快速切换工程不显示旧工程图。
