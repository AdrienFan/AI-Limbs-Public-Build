# 你画我猜系统出题第一版

原状：仅自由出题，系统按钮禁用。范围仅draw-guess子插件，复用画室0.2.98主画布和通用动作表单；基座和父插件业务不改。

目标：低／中／高各30题，随机难度从所有未使用题目合并均匀抽取。当轮画方选模式和难度，系统私下分配词语和两条提示后开始作画。猜方保持只读、交图后才可猜测、猜错逐条解锁提示；精确匹配不变。选择阶段3秒查询，作画阶段5秒。题库耗尽明确提示，不重复旧题；返回选择不消耗题目；成功抽题后不能重抽或改题。

步骤：
1. 增加词库、校验、无放回随机选择及剩余数量。
2. 加入难度阶段、选择／返回接口、双方权限和私有系统题目；复用画布创建和三次猜测。
3. 补题库均匀候选范围、耗尽、视图保密、角色交换及状态查询回归源码；更新0.1.8与API示例。
4. 静态核对后提交、启动云端构建，不执行本地编译，不持续监控。

验证待完成：云端测试与手机部署后的双向系统模式、四种难度、主画布及提示解锁。

源码完成：SystemQuestionBank、DIFFICULTY状态及choose_difficulty/back_mode、双端私有系统题目、提示解锁与系统题库耗尽处理已实现；已补回归源码并同步0.1.8版本。包入口、父插件契约与版本静态检查及git diff --check通过。未执行本地Gradle测试或编译；云端和手机验收仍待完成。
