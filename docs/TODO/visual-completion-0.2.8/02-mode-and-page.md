# 自动选择观察方式

新增通用 observe 能力，所有桥通过既有能力目录调用；无需专用桥逻辑。auto 查询完整当前 UI 快照后，按可读/可操作节点、可见节点和大 Surface 覆盖率作启发式选择。UI 返回固定 page；visual 返回一帧和简短 page_evidence，固定快照仍可续读。结果附原因、阈值策略版本和统计。mode=ui/visual 可明确覆盖；明确 visual 跳过 UI 树，get_frame 不受分类额外开销影响。

图像只使用已有 READY 会话；不自动授权或开会话。UI 错误/无有效快照直接失败，不做错误降级。无障碍虚拟节点丰富的自绘组件可以走 UI；不按包名断言游戏。页面与图像顺序采集，不保证原子一致。

page.inspect 附自动建议，工作台显示节点优先或图像优先及可读节点数。page.text 修正公开 limit 默认 12000 与实际实现的差异，公开 field，保留固定快照与 Unicode 边界规则；快照深度和节点数有明确上限。
