# 01 实现与边界

以前直接用系统 DNS 解析回调域名，遇到 VPN fake-ip 会与公网地址检查冲突。改为显式配置的 DNS over HTTPS 解析服务，不使用固定 VPN 节点、回调 IP 或 bootstrap IP。

解析服务自身通过系统 DNS 和当前手机路由连接，正常 TLS 校验允许与 VPN 的域名映射机制配合；返回的回调地址仍全部接受公网检查，不接受私网、假 IP 或混合污染回答。原回调域名用于 SNI 和证书验证，禁止重定向。

每次回调建立新连接并重新解析，不持久缓存地址；解析服务只有一个当前配置，失败明确报告，不轮换服务或退回 fake-ip。手动填写的是 HTTPS DNS 服务地址，绝不是 VPN 节点或事件回调 URL。

配置通过子插件面板和元数据存储实现；保存后下一次回调使用新值，无需更换隧道密钥或修改手机 VPN。支持修改服务后继续测试。
