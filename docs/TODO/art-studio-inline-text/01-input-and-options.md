# 参数迁移与输入事务

StudioTextOptions是统一工具参数浮窗中的控件，不再创建AlertDialog。包含所有原字体、字号、颜色、行距、字符样式、方向、字距、基线、描边、语言、OpenType、几何、锚点及SVG来源设置。普通正文在画布中输入，原生长按选择的UTF-16范围供参数窗应用字符样式。浮窗只捕获一次参数草稿，正文变化不重置尚未应用的参数。

新建默认参数保存至插件UI偏好；新建文字不会复制上一对象的正文、样式区间、图层ID或修订号。当前输入中的参数修改只改草稿；选中已提交文字的参数修改沿用Store.writeText。SVG源码仍在参数窗编辑；选择转换按钮后才能按正文输入，不默默丢弃SVG逐字定位。已配置的SVG模板可以直接点击画布放置。

StudioCanvasTextInput把原生EditText作为画布的局部输入子View，无参数对话框或全画布点击遮罩。原生Editable保留输入法组字、光标、选区与建议跨度，不用每次回显替换内容。画布矩阵与文字父组矩阵控制输入区位置、缩放、旋转和镜像。输入区采用横排正文编辑；竖排、路径、形状内排版、描边等高级效果仍由原有画室排版器在完成时生成，不宣称输入区就是这些效果的实时排版预览。显式Typeface仅在Host UI输入控件中使用，不进入Resident文字渲染。

输入只改UI草稿，不写历史、不逐字生成整图PNG。键盘完成或底部完成按钮提交一次TEXT_CREATE/TEXT_UPDATE；点击另一画布位置先完成当前文字，再使用最新已显示修订放置下一光标。新建空光标取消不产生对象；已有文字清空时明确拒绝完成，可取消保留原对象，或使用既有图层删除。未改动的已存对象完成时不写新事件。

输入会话在Host进程内保留，页面因全屏或回工具箱重建时继续持有正文及最初修订；不是进程退出后的草稿磁盘恢复。参数默认值独立持久保存。切换工具先隐藏输入区，未完成正文仍保留并可按输入继续。

已有文字输入开始时，捕获原修订与只读资源句柄，在锁外渲染一张隐藏原文字的显示副本，防止旧正文和输入区重叠；不修改工程可见性。资源释放、取消及页销毁时回收副本。准备失败明确显示失败与重试。另端修改使会话过期时保留草稿和复制入口，不自动重定位版本或覆盖其他编辑。

文字完成的提交确认与随后画面渲染分开。Store返回成功即确认已写入，即使资源捕获或显示生成失败也不重放文字写入；画面重新读取，下一光标等新修订显示后再放置。
