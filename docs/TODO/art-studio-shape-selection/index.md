# 基础矢量对象与形状选择

基线0381db2a（0.2.23源码未编译）；用户授权按方案实现。Krita6.0.4 DefaultTool/KoSelection/KoShapeManager要求独立对象，不能用像素选区或整层变换冒充。

仅画室插件：新vector层持有shape数组，每个对象有UUID、基础几何、颜色描边、不透明度、矩阵和锁定/可见性。支持直线、矩形、椭圆、多边形；原paint层笔画行为保留，不迁移旧工程。选中当前vector层后，点击最上层、空白取消、方向框选、Shift/手机多选开关；边框手柄缩放/旋转和内部拖移，每手势提交一次，原有撤销和保存链路。两端共享模型、Store和命中规则，写操作绑定工程及版本，成功改变画布自动图片回执。
