# 对象对应与安全边界

通过历史创建记录定位当前图层内的原始 stroke.id 或 shape.id，仅允许当前已应用、仍保留独立对象的 STROKE_ADD / SHAPE_CREATE / 无端点接续 SHAPE_FREEHAND。删除追加已有普通删除事件，不使用 REVERT 或 history.goto，不裁掉后续历史。撤销删除时恢复对象，后续构造仍应用。STROKE_ERASE 同步清理 contentOrder 的同 ID stroke 索引。

未应用步骤、初始状态、非独立绘制记录、被合并或删除的对象、路径接续/合成、后续像素移动/变形、锁定对象/图层/父组明确禁用并显示原因。动画核对原记录关键帧与当前持有关键帧，拒绝删除复制帧中同 ID 的另一份内容。历史选择从不隐式定位时间轴。

删除资格只携小字段 canDelete/deleteReason，逐图层缓存 ID 索引，摘要继续省略全历史与对象几何。原始记录用于审计，不物理擦除历史。
