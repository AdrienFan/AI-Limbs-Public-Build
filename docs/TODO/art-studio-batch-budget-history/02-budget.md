# 显式抬笔与预算

旧连续轨迹不改渲染。新segments在每段重启传感器时间、平滑、间距和噪声序号，没有段间移动笔尖；不能用pressure=0暗示断开。每段仍适用原60000笔尖/240000粒子上限，整批120000/480000；原始点最多20000，段最多128。

stroke.budget只读运行同一准备/计数路径；缺省brushSeed按输入项与段号稳定生成，随机动态的预检与提交相符。错误给出数量、上限、scope和输入/段索引；计至首次超限的数注明下界，不声称算完全部。预算通过不代替工程大小、资产、像素/动画等提交校验。预设与资源在预检后变更需重新预检。
