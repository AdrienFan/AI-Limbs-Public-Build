# 成功变更画布后的自动缩略图

初始实现基线 d114d6fd；0.2.15 已部署，当前 0.2.16 修复源码待编译。保留现有返回字段，凡修改工程或切换当前画布的成功工具自动附带 thumbnail 元数据与 MCP image 内容块。细节由 canvas.region 只读接口按画布坐标读取。

统一能力入口把操作及缩略图生成放在同一跨进程锁内，预览不落盘、不加入工程历史。手机使用原有实时画布，AI 使用同一次调用的图片回执。默认长边 256，局部图支持放大并限制尺寸。

作用域：画室插件和两条接收端的通用图片结果适配；不修改基座。RDC 保留图像内容块；SentinelX exec 的云端仍是文本包装，图片应从同一次返回的 mcp_content 内容块直接呈现，不能误称编码文字就是可见图片。原文本分页与错误语义保持。
