# 画室 0.2.99：工具缺漏第一批

本轮用户明确要求：先补围合填充外围颜色、磁性套索闭合调整、漫画分格路径处理；不推送、不云编译，后续缺漏补齐后统一编译与测试。

## 本批源码范围

- 围合填充新增 surrounded_color / surrounded_transparent / surrounded_color_or_transparent，沿围合边缘搜索外部区域，反选后限制在围合内。includeSurrounding 默认 true；includeContour 独立控制接触围合边缘的连通结果。保留容差、软覆盖、缺口处理、既有选区、图案、混合和单次历史入口。
- 磁性套索分为绘制、闭合调整、确认。闭合后可拖动、沿真实吸附边缘插入、拖出参考范围删除锚点；Enter第一次闭合、第二次确认。取消不改变原选区，只有最终确认写一次历史。提交后重新恢复磁性锚点仍不在本批范围。
- 分格对闭合轮廓做文档坐标路径布尔运算，支持凹轮廓、孔洞、椭圆／曲线和多子路径。结果是可编辑折线路径，输入曲线误差上限0.25文档像素，不保留原始三次控制柄。每结果最多2048段、64轮廓，超过预算明确拒绝。
- 合并可处理相对非平行边及同一对象孔洞两侧，只桥接边段共同投影范围，不取整个凸包；桥宽0–512px（不含0），桥内与已有轮廓重叠时拒绝。原样式、对象／父组变换、图层顺序和已有原子替换历史继续使用。
- toolbox.catalog、能力参数说明、手机参数面板同步。版本0.2.99 / versionCode102 / applicationId v0299，插件身份保持 plugin.art.studio。

源码修改与差异核对完成；增加7项纯蒙版回归用例源码。未执行单元测试、编译、打包、推送或设备安装，不宣称功能已经实测通过。

## 统一编译后的验收清单

1. 围合：封闭色环内外同色、开口泄漏、透明／颜色混合包围、包含包围色、碰到围合边界、软覆盖、缺口半径、现有选区裁限、反选和撤销。
2. 套索：闭合不提交；拖动／插入／删除后重算；少于3锚点重新开放；参考或工程变化取消；后台计算中反复拖动与取消；确认仅一条历史，取消恢复原选区。
3. 分格：0间隙、矩形与椭圆、凹形、带孔、多轮廓；有限手势只穿过部分轮廓须拒绝；父组旋转缩放、局部样式、孔洞内间隙、非平行边、第三格重叠、超预算无半提交；撤销／重做／保存重开。

## 后续缺漏仍需独立补齐

图层变换／组内像素写回共用化；磁性套索标签参考与LoG分块缓存；独立选区蒙版及旋转／角度吸附；分格物理单位及预设、精确保留曲线的布尔编辑；上色蒙版大画幅与动画；修补跨层取样及分组变换；HDR全链路。

Krita参考用于辨析交互与算法职责；本批使用画室既有Kotlin／Android模型实现，没有引入Qt、Krita运行时或宿主特判。
