## 表示与格式边界

- 分格布尔输出采用0.25文档像素误差的可编辑折线路径，不保留原三次控制柄；这是已采用的几何表示，并不宣称精确曲线布尔或Krita全功能等价。每结果最多2048段、64轮廓，超过明确拒绝。
- EXR支持单部件扫描线RGB(A)/Y(A)、HALF/FLOAT、NONE/ZIPS/ZIP，按chromaticities及Bradford转换到线性Rec.709；无色度属性按EXR默认Rec.709解释。遵循EXR预乘alpha惯例，负值、>1亮度与alpha=0的发光RGB均能编码保存。
- 不支持EXR平铺／深度／多部件、PIZ等其他压缩及Ultra HDR JPEG增益图；明确报错，不丢通道、增益图或偷偷量化。普通PNG/JPEG等输出明确为SDR，HDR输出选EXR。
- 保留原归档资源槽名称及PNG资产；新增EXR按内容检测。旧工程不需重写历史。选区覆盖率／标签编码使用8位是蒙版精度，与作品16位浮点颜色不同。
- 上色输出≤16777216像素，每求解块≤1048576像素，粗层≤262144像素；滤波半径受重叠预算约束。边界／小种子与分块竞争仍需实际画作验收，结果并不保证与整图高内存求解逐像素相等。统计中的seed／cleanup在分块模式包含重叠工作，回执显式标注。
- 动画蒙版单独保留每帧线索和输出；转换当前缓存为绘画层前要求明确停用该轨道，防止其他帧的数据被改成不匹配的图层类型。

## 验证

兼容API29的有界流读取不依赖API33的readNBytes；云端同时检查最低支持版本和API34。

静态能力注册、267项清单／帮助、216叶子菜单、83回放事件足迹标签与差异空白检查已通过。没有在手机本地执行Gradle构建。

统一云流程包含：

1. 既有JVM回归，新增7项外围包围用例；有限binary16全部65536编码的往返与RNE边界；官方OpenEXR 3.3.5生成的FLOAT ZIP与P3 ZIPS夹具；HDR／负值／预乘与零alpha发光、无效输入预算、浮点PatchMatch和LoG跨块用例。
2. 独立OpenEXR 3.3.5读取Kotlin写出的HALF ZIP文件，核对真实通道，避免同一实现自测掩盖格式错误。
3. API29及API34 Android模拟器执行真实Skia／JNI，用例覆盖低于8位量化间隔的16位PNG差值、HDR导入／合成／围合／撤销重做／工程归档重导入／EXR匯出、分组变换写回、动画上色蒙版与修补。
4. 四ABI APK、签名.ailp与来源证明；验证报告一起上传。手机上的手势、复杂分格、分块交界和旧作品重开仍需安装后验收。
