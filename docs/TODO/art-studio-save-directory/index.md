# 可更改的画室默认保存目录

基线为画室 0.2.14，Git HEAD 9b2782dd2f06b6d0d69ccc7342499f6783215b11。
设备已部署这个版本。本轮是兼容迭代，不修改 .ailart 格式或既有能力参数。

保留插件内的默认位置，新增用户可编辑的绝对目录路径。工程、导出图片和增量备份按 documents、exports、backups 分目录保存。
已保存工程保留原路径；草稿、资产、摘要、足迹与目录配置保留在插件工作区。本轮不自动搬迁或删除旧作品。

作用域仅为画室插件、manifest、插件说明。页面和兰儿共用配置、保存位置索引和 ArtStore 的跨进程文件锁。
目录设置前创建并删除写入探针；验证失败保留原设置，写入失败明确报错。恢复插件内目录是用户显式操作，不是失败时的回退。

手机从设置菜单更改目录，兰儿通过 storage.settings / storage.set_directory 读取和更改。
导出和图层输出使用同一目录。现有默认模式的系统文件选择器保留；设置自定义目录后手机默认直接输出，仍可显式选择其他位置。

用户要求本轮不推送云端编译。源码静态检查完成后保留本地提交，编译与实机验证随后续优化统一安排。

源码实现与静态审阅已完成：开发版本 0.2.15（versionCode 18），manifest 与菜单目录版本一致，菜单 JSON 可解析，git diff --check 通过。未运行编译、自动化测试或实机验证；未推送云端。后续统一验证目录权限、旧工程原位保存、双方入口、另选位置取消及显式恢复默认目录。
