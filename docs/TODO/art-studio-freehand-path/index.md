# 矢量徒手路径

基于0b7bd269的画室0.2.24源码迭代。用户授权实现徒手路径第一阶段；仅画室插件，保留四种基础形状和原有栅格工具，不增加宿主接口依赖。本轮不编译、测试或推送。

Krita6.0.4 KisToolPencil/KoPencilTool通过点采样创建KoPathShape，支持Raw/Curve/Straight以及Shift闭合；矢量层保留路径，绘画层栅格化。本轮实现矢量层路径，使用Android Path渲染和独立Kotlin几何算法，不能直接加载Qt/C++实现。直线化使用距离精度简化，不承诺与Krita角度合并参数相同。

- [x] 路径对象保存开放/闭合、直线及三次贝塞尔段，复用渲染/命中/变换和资源限制
- [x] 原始/曲线/直线化模式，精度控制和共享shape.freehand能力；算法结果一次写入日志
- [x] 手机历史触摸采样、轨迹预览、选项和捕获工程版本，复用选择/撤销/保存/缩图
- [x] 版本与用户/AI说明、源代码审查和Git提交

路径节点/控制柄编辑、端点接续、矢量笔压宽度/笔刷纹理本轮不做。原始采样最多2048点，超过明确拒绝；每条路径最多2048段/6145几何点，复用单层32768点预算。拟合后台运行，迭代分段避免递归栈，渲染无需默认字体。后续编译安装后验收三模式、闭合填充、组变换、并发、选择与工程往返。
