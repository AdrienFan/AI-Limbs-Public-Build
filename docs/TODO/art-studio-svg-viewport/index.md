# SVG代码区域越界绘制

## 现象和证据

阿伟2026-10-03提供两张截图：短代码时画布在上、代码区在下正常；打开复杂作品后，SVG文本与选择高亮越过下方代码区，覆盖画布、分隔条及编辑工具条。
基线0.2.71，仓库HEAD b001ef8605c6fcafc5ca5cef8fe2e01fa437aba4。此前绘图体验优化未提交，继续保留。

源码StudioSvgCodeView已有纵向ScrollView和横向HorizontalScrollView，不是缺少滚动容器。Compose分屏Box、编辑器Column和AndroidView边界均未显式裁剪；原生根未设边界outline/clipToOutline，长文本滚动时存在越界绘制通道。
Android官方AndroidView API文档明确说明默认不裁剪到布局边界，建议对子View设置clipToOutline：
https://developer.android.com/reference/kotlin/androidx/compose/ui/viewinterop/AndroidView.composable
框架行为与截图一致；完整因果和触摸效果仍需新版实机验证，不宣称已验收。

13:47阿伟补充复现：长代码拉到最底后，继续向上拉并保持不松手，分屏窗口会恢复。该事实表明症状与滚动位置/拖动状态相关；滚动中的绘制边界或边缘效果是排查方向，尚不能仅凭此证明是哪一个框架阶段出错。不要把代码内容高度、实际分屏布局尺寸和越界绘制混为一个原因。
当前修复使Compose分屏与原生代码视口均有明确矩形裁剪，不依赖拖动或回弹才恢复。尚未编译安装，不能把源码修正表述为实机问题已解决。
