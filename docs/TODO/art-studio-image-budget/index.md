# 画室图片尺寸与内存预算

基于已部署 0.2.15 的现有开发分支继续迭代，保留 0.2.16 空画布反馈修复。只修改画室插件；本轮不上传云端编译。

原实现要求画布两边为 64–4096 px，打开图片把格式解析失败也报成尺寸错误。新实现统一结构边界与动态工作预算，打开图片和导入图层共用预检及显式缩小确认。尺寸不足 64 px 的有效图像不再被拒绝。

1. 统一 1–16384 px 结构边界；按照进程堆剩余空间保守估算像素处理预算。重放历史只验证结构，避免可用内存波动改变历史。渲染、导出在实际分配前检查预算。
2. 解码前读取真实尺寸和 MIME。超出边界或预算时返回原尺寸、建议尺寸、原因及与源文件绑定的确认参数；未确认不解码、不写资产、不创建工程。确认后采样解码、精确缩放，释放临时位图，任何预算变化都重新请求确认。
3. 手机打开/图层导入弹出确认框；兰儿 document.open_image、image.import、menu.execute 获得 needs_confirmation、operationApplied=false 和确认参数。现有调用无需新增必填参数。成功返回实际尺寸与是否缩小，保持自动缩略图反馈。
4. 新建、裁切、画布调整、剪贴板、导出共用结构规则，删除旧像素硬编码；文件体积限制另行保留。更新说明、版本号并静态检查；实机验收留到用户要求云端编译并安装之后。
