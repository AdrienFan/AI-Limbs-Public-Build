# 工具参数浮窗

当前左侧窄工具栏混合工具图标、参数和说明，部分选项又打开模态对话框，妨碍边画边调。

把所有工具格的双击入口接到同一个插件内浮窗。单击保留现有选择行为，待实现工具保持不可执行。迁移现有选项控件，删除旧侧栏控件和旧选项模态框。浮窗支持拖动、标题栏最小化、恢复、关闭，限制在画室内；点击窗口外画布继续绘画。

作用域：画室插件页面、复用浮窗、工具目录、插件内共享视图状态和 capability/manifest、版本及说明文档。保持现有绘画数据接口和宿主架构；本轮不编译、不上传云端。
