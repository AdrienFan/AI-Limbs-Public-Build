# 搜索来源与候选组织

明确 scope 只读取该 owner 当前注册的元数据。精确注册 ID、调用别名和唯一显示名直接定位，重名显示名不能随机选中。原生地址读取 Host 元数据；其他跨模块查询收集完整目录。

模块名来自当前注册的 owner ID、显示名和共享调用命名空间，不内置具体插件业务 ID。英文模块名使用完整词边界，汉字显示名支持句内识别。明确模块时剥离模块名再检索具体意图，唯一动作名可直接得到叶能力，歧义动作保留候选。

Resolver 的全目录候选在 owner 路由、折叠及排序之后才应用用户 limit。CLI 等原有 ToolCapabilityCatalog 消费者仍保留最多 20 条的既有返回限制。

弱查询只报告 low_confidence，不再触发整库强制扫描和第二次检索。显式详情或调用检查的既有 package refresh 行为不在本轮移除范围。

plugin.* 目录以当前 canonical registry 为准，Host 原始工具表中的插件条目不能覆盖已注册的完整元数据；卸载后的孤立条目和旧别名不能重现。Core 声明的通用兼容能力仍由 Core Registry 发布。
