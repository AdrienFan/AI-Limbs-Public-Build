# 你画我猜第一版

范围：画室通用互动扩展/临时画布，以及独立draw-guess子插件。基座、Hub、插件中心不改。原菜单扩展API1继续支持旧InProcessUiStateProvider绑定，新增结构化互动业务绑定。游戏答案只在子插件内存保管，猜测接口和手机对手视图不泄露未解锁信息。

步骤：核对现有规则与源码；提供可收起拖动浮窗和独立临时画布；实现双方准备/掷骰确认/赢家选顺序/封词/两条提示/交图/三次猜测/自动交换；补双方准备规则、兰儿能力示例、测试源码和云端签名工作流。

自动字数提示在交图时给出；第一次错揭示提示一，第二次错揭示提示二，第三次错失败。猜中或失败均公布答案、释放本轮画布并交换角色。没有系统提词。

版本：画室0.2.96，子插件0.1.2。仅静态核对与源码提交；用户后续已授权完工后直接云编译。

[实现](01-implementation.md)及[验证](02-validation.md)完成。
