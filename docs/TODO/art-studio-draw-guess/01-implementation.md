# 规则、浮窗与临时画布

旧菜单绑定只有菜单状态/事件。新增结构化互动绑定，保留已有InProcessUiStateProvider类型、菜单schema1、扩展点/API1。父插件按校验过的子插件身份连接仅供该实例使用的临时画布endpoint；互动业务只在Child Entry运行，Host显示端通过父插件聚合provider回送手机事件，不构造第二份游戏业务。

规则覆盖双方准备、两次独立掷骰与确认、同点重掷、赢家决定顺序、封题和两条提示、交图、字数星号、三次猜测、自动清理与换角色。前置阶段和revision校验拒绝越权/过期动作。双方准备入口均返回极简规则与下一步。

临时ArtStore位于画室cache子目录，正常工程不切换指针。活跃标记撤销后拒绝旧任务写入；封图后拒绝写入；任何临时存储写入不得越出实例目录。图片只在交图或兰儿显式preview/picture时产生，不做用户操作缩略图反馈传送。手机收到目录内PNG引用，避免把大图片放入UI状态传输。
