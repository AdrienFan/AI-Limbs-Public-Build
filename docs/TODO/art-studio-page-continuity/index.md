# 画室页面切换时保持已完成画面

基线 4242a664 / 画室 0.2.74。阿伟报告全屏、退出全屏以及返回工具箱再进入时先出现“尚未创建画布”，稍后才显示原画面。

核对源码：Host 的 normal / immersive 分支会重建页面；画室 Compose 在 detach 时释放，重建后 snapshot/image 初值为空。0.2.68 已有空快照初始化，0.2.71 新增退出时释放预览位图，当前慢作品重新合成会将原有初始化窗口放大。不能仅凭现象认定该机制全部始于最近两版。

修复限定在画室插件。页面 Provider 持有最近一次接受的完整渲染帧；页面只借用该帧，退出释放页面借用和回调，Provider 保留一帧供重进。新帧替换、真正关闭工程和 Provider 停用明确释放；重叠页面通过借用计数避免使用已回收的位图。不保留 Activity/View 或后台页面连接。

重进先显示最近完成画面，后台核对工程修订标记；未变化直接恢复，不重复合成。核对期间禁止编辑，工程已切换或关闭时按当前状态更新。首次加载未完成与真正无工程分开，恢复失败明确报告并提供重试。

计划：

- 增加帧借用与生命周期管理
- 接入页面刷新、编辑、关闭与 Provider 停用
- 补充借用、替换、关闭及重进的 JVM 回归源码
- 静态检查，不做本地测试或编译；保留待与基座通信修复统一发布



实施完成：Provider 缓存只保存一个完整帧；页面初始化借用快照、画布和参考位图；未变化的 revision 不重复合成；刷新、编辑、关闭统一转移帧借用；页面退出保留缓存且释放原生 View 引用、菜单回调和页面连接；Provider 停用释放缓存所有权。旧 Activity-result 回调结束也不能绕过恢复期间的 busy 状态。
