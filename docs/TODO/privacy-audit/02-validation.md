- 实机只读能力检查：Android 16、API 36、Shell uid 2000、用户 0 与 150、Clash 包存在。

- 使用隔离的临时 Android/JSON 类型桩和已存在的 Kotlin 编译器进行源码类型检查；这不是 APK 构建，也不替代真实宿主运行验收。

## 云端任务

`android-build.yml` 在本功能分支只运行隐私审计构建：核心检查 → 安装契约检查 → 隔离 Gradle payload 编译 → 使用已有官方父插件签名身份打包 → 验证签名与 payload 摘要 → 上传 `.ailp` 和 `.sha256`。

隔离构建入口 `privacy-audit-build/` 只引入插件 SDK 和新插件，不构建基座或其他插件。提交并触发成功即交还用户，不轮询构建状态。
