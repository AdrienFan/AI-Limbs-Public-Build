# 视觉 0.2.10 动作闭环迭代

0.2.9 实测普通点击的 Host 动作阶段 1852–1961 ms，new_frame 观察约 740–836 ms。暂停菜单的指定区域在无点击对照中仍重复报告 18/35 采样点变化。基准采样与轮询采样解释不同，但具体差异未实机证实。点击反馈层被截图且纵坐标偏移；旋转会中断点击后的观察；部分参数只返回 Failed requirement。

视觉业务保留在插件，基座仅优化通用 Host 请求、触控反馈、手势完成和帧计时。ChatGPT 桥没有已证实的返回错误，不纳入本次改动。网络和远端处理波动单独归因。

## 步骤与范围

1. [采样与参数](01-sampling.md)：统一原始采样、保留同帧诊断、可选 dynamic 策略及精确错误。
2. [动作观察](02-action.md)：点击后旋转重建基准、一次注入、反馈可控及计时。
3. [验证与发布](03-validation.md)：云端测试、构建、版本和部署验收；不本地编译。
