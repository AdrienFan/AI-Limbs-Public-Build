# 验证与发布

云端工作流运行视觉 JVM 回归、能力声明检查、版本来源检查、编译与签名。基座云端检查唤醒竞态、生命周期分离、后端懒探测和手势终态。构建结果另行记录，提交源码不等于已部署。

部署后核查静止暂停菜单的相同 ROI、动态变化、PNG 存图后等待、不同预览尺寸、点击后横竖屏切换、折叠屏几何、关闭反馈圆环与开启后的实际位置。核查途中停止及取消不会重复注入。对同场景和画质记录本地动作与整体工具的耗时分布，外部 POST 波动单独报告。

在 Chat 和 Work 使用同一非敏感测试图与 media_id，比较顶层图片块和实际可识别内容；本次不宣称已修复 Chat 视觉输入。历史 51.4% 的具体像素差异仍待 sampling 诊断确认。
