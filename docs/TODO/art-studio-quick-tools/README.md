# 画室底部快捷面板

本轮在 77ff2ba3 的 0.2.68 基础上新增固定快捷区。上方工具列表的单击选择、双击参数行为保留。

1. 插件自持久存储：默认两空位、稳定 ID、一次加一位、上限八位；清空和移除独立，配置修订号防止并发覆盖。
2. 页面布局：滚动工具列表占剩余高度，底部只布局实际两列行数；快捷单击选工具，双击配置。
3. 手机与兰儿共享 read/configure/use，参数 schema 与紧凑示例齐全；选择复用页面通信通道。
4. 递增至 0.2.69/versionCode72/applicationId v0269，静态检查、提交和推送累积改动；只在云端执行测试和编译。

移除最后一位后不自动补位，空面板提供明确的添加入口。配置不进入作品历史，不保存独立工具参数。
