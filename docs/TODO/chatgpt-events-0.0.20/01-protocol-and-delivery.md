# 01 协议与投递

增加 server/discover、events/list、events/subscribe、events/unsubscribe。初版只支持 ai_limbs.wake_requested / source_id=manual；旧 initialize 和工具调用保持兼容。

订阅按认证隧道、URL、事件名和规范化参数确定身份，验签挑战成功后才激活。HTTPS 连接拒绝非公网目标与重定向；签名采用 Standard Webhooks。验证缓存五分钟，换密钥重新验证并在六十秒内双签名。

AES-GCM 存储订阅和待发事件，重启保留事件 ID/正文，只重发投递，不重新执行手机动作。限十六条订阅、三十二项待发、十六份诊断；事件十五分钟到期，最多四次投递。410/413 不重试，410 停止该订阅。退订与投递串行，退订返回后旧订阅不再开始回调。

新增纯协议单元用例与隧道模拟集成用例，覆盖独立 HMAC 向量、校验失败、非法目标、密钥轮换、有限重试、重启、隔离、到期、容量和取消。此处记录的是源码用例，不代表已运行或实机验收通过。
