# 工程保存位置确认

菜单保存须在写入前明确原文件与默认工程目录的选择。普通 PNG、JPEG 等图像打开后保存为 .ailart 工程，图片导出继续走独立入口。

## 执行与来源

已核对 ArtStudioPage 的手机文件打开、保存、关闭前保存，以及 ArtStore 的 archive、外部链接和保存目录索引。可写外部 .ailart 原逻辑会自动覆盖；普通图像没有外部工程链接。

0.2.86 菜单保存外部工程先弹窗：覆盖原工程、保存到默认目录、取消。默认目录采用当前 projectsDirectory，并在成功写入后解除原链接；保留文档 ID、完整历史和动画，不通过复制当前状态重建工程。后续保存使用该工程位置。关闭前保存复用同一流程。

取消不调用写入事务。执行时核对 documentId、expectedRevision 与 externalUri；校验、存档、外部同步和可选关闭使用同一跨进程文档锁。覆盖失败保留待同步状态和活动工程，不自动切换保存目标，也不显示成功。已发布 document.save 能力与结果契约保持不变，确认由菜单 UI 承担。
