# 消息协议与持久化（已完成）

## 旧实现

AI Limbs 没有面向聊天终端的正式消息邮箱。此前验证链路使用临时 HTTP 服务和内存队列，不能随
应用重启恢复，也没有明确的幂等与取消语义。

## 修改

- 建立应用内 `LanerChatBridgeService`。
- 持久化会话、消息状态、递增序号和回复结果。
- 分离轻量通知与正文读取接口。
- 对回复、取消和会话关闭实施幂等检查。
- 长轮询设置严格的有限等待上限。
- 修复通知检查与 StateFlow 订阅之间的到达竞态；精确 `request_id` 可跨活动 Session 拉取。

## 期待结果

RDC 只传递结构化工具调用；消息正文不会从通知探测接口泄露；`DELIVERED` 但未回答的消息在重新
接入后仍可读取。App 重启后的聊天气泡补写与 Agent Lease 属于后续 Reliability 阶段。
