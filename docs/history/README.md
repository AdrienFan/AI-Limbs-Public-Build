# Bridge history

This directory preserves historical Bridge design notes migrated out of AI-Limbs-Base.

Canonical current ownership:

- Bridge business ABI: `plugin-lab/sdk/bridge-contract`
- Bridge parent runtime: `plugin-lab/plugins/bridge-core`
- RDC / SentinelX / TRIGGERcmd: Bridge child extensions under `plugin-lab/extensions`
- External Host entry: generic `host.ingress@1 / invoke`
- Resident startup: generic manifest dependency restore; there is no Bridge-specific Resident stage

Historical documents may describe superseded Base-owned contracts or private ingress capabilities; they are retained only as migration history and are not normative architecture.
